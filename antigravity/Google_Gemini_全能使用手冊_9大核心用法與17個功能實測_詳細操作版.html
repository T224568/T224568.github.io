🛠️ 核心自動化 Tool 工具操作說明（YouTube 轉雙軌報告工具）

專案內建 Tool：scripts/youtube_to_pdf_preview.py 全自動化 CLI
【工具功能概述】
輸入任意 YouTube 網址，工具自動調用 yt-dlp 提取標題、發布者、時長、章節（Chapters）及簡介，自動套用 A4 最佳排版樣式渲染出 HTML，並藉由 Google Chrome Headless 引擎秒級輸出高品質 PDF，自動雙軌存檔於 /Volumes/512G/Antigravity/。
【依賴環境與工具鏈】
• yt-dlp：用於免登入、無防爬阻礙提取影音 JSON 元數據。
• Google Chrome：作為無頭排版引擎（Headless Chromium Engine），保證 CSS 100% 精確渲染。
• Python 3：自動化調度管道與動態內容組裝。
【CLI 指令調用方式】
# 基本用法（預設自動存入 /Volumes/512G/Antigravity/） python3 scripts/youtube_to_pdf_preview.py "https://youtu.be/RBbvc1Ap9gk" # 自訂報告標題與輸出目錄 python3 scripts/youtube_to_pdf_preview.py "https://youtu.be/RBbvc1Ap9gk" -t "Gemini_全能使用手冊_最新實戰版" -o "/Volumes/512G/Antigravity/"
【產出成果雙軌特性】
1. .html 預覽檔：在 Antigravity / Cursor 右側面板直接點擊即刻開箱預覽，無須下載。
2. .pdf 正式檔：向量字體、A4 分頁標注，供離線列印、歸檔或外部分享。

模組一｜YouTube 長影音內容極限提煉（功能 1 & 2）
