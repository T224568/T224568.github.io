🛠️ 第一部分：基礎權限快速設定（日常必備）

1. 使用者主密碼變更流程 (User Password)：
開啟電池背蓋按「設定鍵(I/R)」 → 面板輸入新密碼 (4~10位數) → 再按「設定鍵(I/R)」存檔完成
2. 感應卡片批次登錄 (最高支援 100 張)：
按「設定鍵(I/R)」 → 依序感應卡片 (聽到嗶聲) → 再按「設定鍵(I/R)」存檔完成

📋 第二部分：進階選單管理架構 (喚醒 ➔ 輸入主密碼 ➔ 按設定鍵)

選單代碼 功能項目 操作路徑 適用情境與安全特點
1# 訪客密碼
(Guest PIN)		 新增：1# → 1# → 輸入4位數 → #
刪除：1# → 3# → 輸入主密碼 → #		 親友來借住一週使用；在手動刪除前可重複開門。
2# 一次性密碼
(One-time PIN)		 新增：2# → 1# → 輸入4位數 → #
刪除：2# → 3# → 輸入主密碼 → #		 水電維修、清潔打掃；成功開門一次後即焚失效。
3# 刪除所有卡片
(焦土防護)		 執行：3# → 3# → 輸入主密碼 → # 一般模式無法單獨刪除單卡；遺失卡片必須全刪重設。
4# 模式變更
(進階切換)		 執行：4# → 1# → 設定管理者密碼 → # 切換為進階模式（⚠️ 原密碼與卡片全數格式化重置）。
⚠️ 資安關鍵提醒（同生共死機制）：
一般模式（General Mode）沒有為卡片編列卡號索引，因此無法單獨刪除單一張卡片！若家中有人遺失卡片，請立刻至 3 號選單執行「刪除所有卡片」，並將其餘家人的卡片全數收齊後重新批次登錄。
💡 隱藏實用技巧：
- 虛位密碼防窺 (Fake PIN)：一般模式專屬，在輸入真實密碼的前後隨意輸入亂碼數字，只要連續包含真實密碼即可開門，可防止旁人偷窺與指紋殘留。
- 外接 9V 電池緊急救援：若電池完全沒電，去便利商店買 9V 方形電池頂住室外面板底部金屬接點即可臨時通電輸入密碼。

🎙️ 第三部分：20 頁深度教學演練講稿節錄

Page 1-3 破冰與安全防線
設定時門扇必須常開
在開始前請牢記鐵律：『保持門扇開啟，手動轉動旋鈕上鎖』。門開著，才能避免設定錯誤時將自己鎖在門外。
Page 4-6 存檔核心機制
認識設定鍵 (I/R 鍵)
電池蓋內的設定鍵就像 Word 的 Ctrl+S，流程的起始與存檔皆須按它。未按設定鍵前，任何輸入均不生效。
Page 7-9 選單記憶口訣
1訪客、2單次、3刪卡、4切換
進入後台選單後，次級邏輯一律是『1 代表新增 (Add)，3 代表刪除 (Delete)』，掌握通則免看說明書。
Page 17-20 必殺技與總結
虛位密碼與三大箴言
『設定永遠開著門、存檔必按 I/R 鍵、遺失卡片 3 號房全刪除』。這不是冰冷機器，是保護全家的智慧管家。
