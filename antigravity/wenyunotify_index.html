🎬 Concat 免費剪輯（2026/11/06）

  • 定位：號稱免費版 CapCut（測試版 v0.2.8 / v0.2.9），官網｜GitHub｜教學影片
  • 設定要點：File / Settings 切【繁體中文】，下載「轉錄器（語音轉字幕）」與「語音（TTS）」模型。
  • 實測優缺：支援點到即分割、定格/倒轉、子母畫面、關鍵影格（縮放/位置/旋轉/不透明/音量/遮罩）及匯出入 SRT；目前片段移動較受限、自動字幕偏簡體、只能匯出 MP4，但對國小剪輯教學已相當足夠。

🌊 Google Flow AI 短影片工作流

  • 代表場次：2026/11/14 教育科技展 S4A 短講（錄影｜講義）與 47 Google Flow。
  • 80 秒短片四步驟：① 用 Gemini 生成故事腳本與角色一致性（11 張關鍵幀中英文 Prompt）→ ② Flow 生出 11 張圖（01~11）→ ③ Gemini 生成 10 段「首尾幀」動態與旁白 Prompt → ④ 用 Veo 首尾幀生成每段 8 秒（720P/1080P）再串接。
  • 注意事項：可生成中文語音，但畫面中文字易亂碼。

💻 Vibe Coding 教學小工具實戰

  • 系列教材：共 4 篇＋作品集（上集｜下集｜二上｜二下），搭配 EZPage 一鍵部署至 GitHub Pages。
  • 教師實戰作品：班級小管家、互動式座位表、閱讀打卡牆（Firebase / GAS+Sheet）、多人作文平台、教師情緒彩虹卡、感恩夢想牆。
  • 風險提醒：留意可維護性、除錯難度及 API 金鑰/資料庫安全性（「小孩拿大槍」）。
