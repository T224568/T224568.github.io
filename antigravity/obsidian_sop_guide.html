📂 一、Obsidian 筆記庫 (Vault) 架構與儲存位置

你的 Obsidian 唯一主力筆記庫為 secondbrain，由背景排程 com.jktai.obsidian.sync 每 5 分鐘自動執行 ~/.config/obsidian_sync/sync_vaults.py 維持三端鏡像：

儲存端點 絕對路徑 角色定位與設定重點
1. Google Drive (Mac 主力) ~/Library/CloudStorage/GoogleDrive-jktai123@gmail.com/我的雲端硬碟/secondbrain Mac 版 Obsidian 直接開啟的路徑。
✅ 必做設定：在 Finder 右鍵點選 secondbrain ➔ 「永遠保留在此裝置上」（保持實心綠點 🟢）。
2. iCloud Drive (行動端) ~/Library/Mobile Documents/iCloud~md~obsidian/Documents/secondbrain 供 iPhone / iPad 行動端 Obsidian 同步閱覽，同時作為本機自動化腳本的第一優先實體讀取快取。
3. 1T_HDD (本地冷備份) /Volumes/1T_HDD/ObsidianBackup 外接硬碟連接時自動透過 rsync 鏡像備份。
⚠️ 防呆提醒（哪個資料夾要開？）：
Google Drive 下的 Vault/（裡面只有 2 份舊 Google 簡報捷徑）與 Obsidian/（空資料夾）皆不是你的筆記庫，不需要開啟！只需要把 secondbrain 設為離線保留即可。

📅 二、每日筆記 (每日筆記/YYYY-MM-DD.md) 三段式自動化 SOP

每日筆記由 generate_daily_note.py 整合 agy-today 與 daily-summary (dz) 自動產生，所有欄位皆由腳本自動抓取填入，不再出現空白欄位（且不嵌入早安圖，保持版面乾淨）。

1️⃣ 🏫 教學（含備課進度）

自動提取當日發佈至 fun.jktai123.com 的互動網頁與教材連結（或教學對話、今日行程），並統計當日發佈件數。

2️⃣ 💡 今日反思

自動統計當日 AI 協作會話場次、累計互動訊息數、發佈網頁數，並條列當日核心完成的任務摘要。

3️⃣ 明日優先事項

自動查詢 隔天（明日）的 Google Calendar 行事曆行程 排入第一優先，並附加上專案延續與每日巡檢待辦。

📚 三、Clippings 網頁剪藏知識庫 SOP

secondbrain/Clippings/ 存放你從 Chrome 剪藏的技術文章、YouTube 影片攻略與 GitHub 專案（目前共 168+ 篇）。

步驟 1：從 Chrome 剪藏新網頁

  1. 在 Chrome 打開想收藏的網頁或 YouTube 影片，點擊右上角 Obsidian Web Clipper 圖示。
  2. 確認 Vault 為 secondbrain，Folder 為 Clippings，點擊 Add to Obsidian。

步驟 2：檢索與閱讀剪藏的 3 種方式

  • 方式 A（Obsidian 內分類總覽）：直接開啟根目錄的 📚 Clippings 剪藏知識庫總覽.md，168+ 篇剪藏已按 6 大主題排好表格，點 [[筆記名稱]] 即在右側分頁展開。
  • 方式 B（線上互動搜尋入口）：開啟 Obsidian Clippings 剪藏知識庫總覽網頁，可按分類膠囊或關鍵字即時過濾，點擊 「💎 在 Obsidian 開啟」 直接喚醒本機 Obsidian。
  • 方式 C（請 AI 直接提煉成簡報或圖卡）：直接對 AI 說：「把 Obsidian Clippings 裡的《AI生成影片攻略》做成互動簡報（或 /d-infographic-notes）」。

步驟 3：一鍵更新 Clippings 分類總覽索引

🔄 四、三層級專案管理 SOP（L1 本地 + L2 GitHub + L3 Obsidian）

💡 冷熱資料分離原則：
• L1 熱資料 (本地 AGENTS.md + handoff.md)：只放一頁讀得完的最新交接狀態與下一步，開工必讀。

• L3 冷資料百科 (Obsidian Antigravity/<專案名>/專案工作流程.md)：保存全歷史對話 ID 表格、長篇決策與 🕳️ 踩坑筆記。

1. 新專案初始化 初始化專案 / project-init 建立本地 AGENTS.md + handoff.md (L1)、初始化 GitHub (L2)、在 Obsidian 建立 專案工作流程.md (L3)。
2. 日常開工 開工 / 我來了 / 上次做到哪 讀取 L1 交接檔、檢查 Git 狀態、列出 L3 Obsidian 踩坑筆記路徑並建議下一步。

4. 收工 / 安全關機 收工 / 關機 / safe-shutdown 執行 512G 雙重備份、Notion 日記同步、sync_workflow.py --all 全專案同步至 Obsidian (L3)、更新今日活躍專案 handoff.md (L1)、刷新今日 Obsidian 每日筆記。

🛠️ 六、常見問題與故障排除 SOP (Troubleshooting)

Q1：在 Obsidian 左側點選筆記時，右側打不開或預覽空白？

  • 根因：Google Drive 桌面版將檔案變成了雲端虛擬佔位檔 (compressed, dataless)，導致讀取逾時 (Operation timed out)。
  • 標準解法：在 Finder 的 Google Drive/我的雲端硬碟 右鍵點擊 secondbrain ➔ 選擇 「永遠保留在此裝置上 (Make available offline)」（出現綠點 🟢）。若仍有個別檔案被鎖定，直接請 AI 從 iCloud secondbrain 實體鏡像一鍵還原即可。

Q2：某幾天的每日筆記上方三個欄位（教學 / 今日反思 / 明日優先事項）是空白的？

  • 標準解法：直接對 AI 說 「幫我回填 YYYY-MM-DD 的每日筆記」，或執行 generate_daily_note.py YYYY-MM-DD，腳本會自動抓取當日行程、網頁發布與對話摘要填滿三大欄位。
