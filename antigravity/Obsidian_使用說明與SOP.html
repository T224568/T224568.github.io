🔄 二、三層級專案管理 SOP（L1 本地 + L2 GitHub + L3 Obsidian）

為了避免每次開啟新對話時 AI 失憶，同時又不讓幾千行歷史塞爆 Token，系統採用「冷熱資料分離」設計：

層級 存放位置 核心檔案 資料定位 AI 讀取與寫入時機
L1 本地 專案根目錄 AGENTS.md
handoff.md		 熱資料（極簡 1 頁）
目前做到哪、下一步 1~3 項		 每次開新對話必讀；收工或關機時自動更新
L2 GitHub GitHub 私有庫 .git 程式碼時光機 開工檢查狀態；收工 commit + push
L3 Obsidian secondbrain/Antigravity/<專案>/ 專案工作流程.md 冷資料（完整百科）
全歷史對話表格、決策原因、🕳️踩坑筆記		 開工只列路徑不讀全文（需查舊坑才讀）；收工/開關機自動寫入

📋 日常 4 大階段標準口令與動作

階段 1：新專案建立 (project-init)

🗣️ 對 AI 說：初始化專案

  • 建立本地 AGENTS.md ＋ handoff.md
  • 初始化 Git 並建立 GitHub 私有庫
  • 在 Obsidian 建立 <專案>/專案工作流程.md 並回填歷史對話

階段 2：打開專案開工 (startup)

🗣️ 對 AI 說：開工 或 上次做到哪

  • 讀取 AGENTS.md 與 handoff.md 摘要
  • 檢查本地與遠端 Git 狀態
  • 列出 Obsidian 筆記路徑（若要查舊 Bug 可說：「讀 Obsidian 踩坑筆記」）

階段 3：隨時更新對話表 (sync-project-workflow)

🗣️ 對 AI 說：同步對話摘要到 Obsidian

  • 地毯式掃描 ~/.gemini/antigravity/brain/ 對話日誌
  • 自動將日期、主題、步驟數與對話 ID 更新至 Obsidian 專案工作流程.md 表格

階段 4：工作結束收工 (shutdown)

🗣️ 對 AI 說：收工 或 shutdown

  • L0：執行 512G 雙重備份
  • L1：改寫本地 handoff.md 最新進度
  • L2：擬定中文訊息並 git commit + push
  • L3：把當日 🕳️ 踩坑筆記（Bug 根因與解法） 寫入 Obsidian

💻 終端機手動同步 CLI 指令

# 1. 僅同步當前所在專案
/usr/bin/python3 /Users/jktai/.gemini/config/skills/sync-project-workflow/scripts/sync_workflow.py

# 2. 指定單一專案路徑同步
/usr/bin/python3 /Users/jktai/.gemini/config/skills/sync-project-workflow/scripts/sync_workflow.py --path /Volumes/1T_HDD_2/Antigravity/20260714Church

# 3. 一鍵地毯式同步全系統所有 19 個專案 (--all)
/usr/bin/python3 /Users/jktai/.gemini/config/skills/sync-project-workflow/scripts/sync_workflow.py --all

📅 三、Obsidian 每日筆記 (Daily Note) 自動化 SOP

每日筆記 (secondbrain/每日筆記/YYYY-MM-DD.md) 由 generate_daily_note.py 呼叫 agy-today 自動生成。重複執行時不會覆蓋你手寫的「🏫 教學 / 💡 今日反思 / 明日優先事項」，只會無損更新下半部的活動摘要：

  1. YAML 屬性與模板：自動替換日期、ISO 週數 (2026-W47) 與星期 (11/22（日）)。
  2. 📋 今日工作日誌與網頁發布 (/dz)：當日新增發佈至 all_html.html 的網頁連結與任務對話直達連結。
  3. 📸 今日手機相片與截圖：統計當日 /Volumes/Haggis2T/POCO手機/ 拍攝的照片與截圖。
  4. 📅 Google Calendar 行事曆行程：同步 macOS 行事曆（jktai123@gmail.com 與 我們的日曆）當日行程。
  5. 🤖 Antigravity / Gemini 動作摘要：當日所有對話的 [時間] 👤 使用者 / 🤖 助理 完整問答時間軸。
  6. 🌐 Chrome 瀏覽器活動：自動分類 Google Search、YouTube、Gemini Web、Google Sheet/Docs 瀏覽紀錄。
  7. 📊 應用程式使用時數 (Screen Time)：統計 Idle/Locked、Chrome、Antigravity、Obsidian、LINE 使用時數與百分比。
# 生成或更新「今天」的 Obsidian 每日筆記

# 指定任意歷史日期回溯補生 (例如 2026-11-21)
/usr/bin/python3 /Volumes/1T_HDD_2/Antigravity/20260730SecondBrain/.agents/skills/daily-ai-tracker/scripts/generate_daily_note.py 2026-11-21

⚡ 四、開關機全自動兜底機制（忘記手動收工也不怕！）

🌅 開機自動補跑 (task_catchup.py)

每次電腦開機登入時，自動檢查 ~/.task_state.json 並補跑當日未執行的任務：

  • ✅ 生成 Obsidian 每日筆記 (generate_daily_note.py)
  • ✅ 同步全專案工作流程至 Obsidian (sync_workflow.py --all)
  • ✅ 512G 鏡像備份、早安圖檢查補生、品陽缺失備份、南門教會台語禮拜影片更新、平日台股更新

🌙 關機自動全專案收工 (safe-shutdown)

無論你對 AI 說 關機、執行 safe-shutdown 或午夜 00:00 自動關機，皆會在關機前自動完成：

  • ✅ L0：512G 雙重安全備份 (1T_HDD_2 + GDrive)
  • ✅ Notion：當日會話梳理同步至 Notion 日記
  • ✅ L3 自動收工：執行 sync_workflow.py --all 同步全部 19 個專案至 Obsidian
  • ✅ L1 自動收工：自動更新當日活躍專案的 handoff.md 最後更新時間與動作摘要
